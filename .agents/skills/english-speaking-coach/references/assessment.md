# Baseline and monthly assessment

Use this reference only for an initial baseline or a later reassessment.

## Baseline tasks

Run tasks conversationally rather than presenting them as a written exam:

1. Give a one-minute self-introduction.
2. Describe a past experience with a beginning, middle, and end.
3. State an opinion and support it with reasons or examples.
4. Complete a relevant work or everyday roleplay.
5. Answer two unprepared follow-up questions.

For a shorter baseline, sample at least one sustained response and one interactive roleplay. Record which tasks were omitted.

## Evidence dimensions

Describe evidence in these dimensions:

- continuity and hesitation;
- clarity of meaning;
- grammatical control;
- range and naturalness of expression;
- organization of longer answers;
- interaction and follow-up ability; and
- pronunciation or prosody only when audio evidence is actually available.

Use qualitative labels such as “emerging,” “functional,” “consistent,” and “flexible,” supported by examples. If a numeric score is useful for before-and-after comparison, state that it is an internal coaching index rather than an accredited proficiency score.

## Baseline output

Identify:

- current strengths;
- three priority constraints;
- one focus for the first training phase;
- an initial practice difficulty; and
- a reassessment date or trigger.

For a monthly reassessment, keep the task types comparable while changing the topics. Compare only dimensions supported by both sessions and note material differences in conditions such as time, audio quality, preparation, or task difficulty.
